# Standard Microsoft Envelope

Корпоративная доставка значений для .NET.

Значение необходимо положить в конверт, адресовать, согласовать и передать сотруднику с подходящим уровнем допуска. Просто вернуть `int` технически возможно, но процедурой не предусмотрено.

## Запуск

Нужен .NET 8 SDK.

```sh
dotnet build src/StandardEnvelope
dotnet pack src/StandardEnvelope --configuration Release --output artifacts
```

## Что работает

- `Envelope<T>`: адресат, конфиденциальность, согласование, запечатывание и однократное вскрытие.
- `ReturnToSender()`: вернуть запечатанный конверт отправителю.
- Вложенные конверты: обычный `Envelope<Envelope<T>>`.

## Опционально: Intent-Aware Correspondence (via BorowAmpersand)

Интеграция с настоящим runtime [амперсанда Борова](https://github.com/jeffry-stroustrup-ei/borow-ampersand) добавляет три режима: снимок значения, живую ссылку и проверку заявленного намерения.

Установите закреплённую зависимость и запустите демо и проверки из корня репозитория:

```sh
git submodule update --init --recursive
dotnet build StandardEnvelope.sln
dotnet run --project demo/StandardEnvelope.Demo
dotnet run --project tests/StandardEnvelope.Tests
```

Тесты — исполняемый проект без стороннего тестового фреймворка. Запускаются через `dotnet run`.

Изменение зарплаты с 300000 до 150000 после отправки конверта с заявленным намерением 300000 приводит к `ENV409`. Обратитесь в HR.

Намерение передаётся явно. Чтение мыслей отправителя в эту версию не вошло.

## Технические границы

Конверты работают в памяти процесса. Проверки адресата и допуска используют переданные вызывающим кодом данные; это не аутентификация и не шифрование. Потокобезопасность не предусмотрена. Снимок ссылочного типа сохраняет ссылку, а не глубокую копию объекта.

Конверт Борова — `ref struct`: используйте его локально в синхронном коде. Для изменения значения пользуйтесь `reference.Value`, чтобы хранилище концептов Борова оставалось согласованным. Синтаксис `&borow` требует инструментов исходной репы; здесь используется прямой runtime API.

Полное API и примеры: [README](README.md). Спецификация: [SME-0001](docs/SME-0001.md).
